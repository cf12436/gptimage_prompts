## 从一张喜欢的图片开始

1. **浏览案例**：先看画面效果，找到适合自己的海报、商品图、人物、插画或信息图方向。
2. **搜索需求**：尝试“咖啡”“旅行”“海报”等主体或用途关键词，再结合分类和风格缩小范围。
3. **复制完整提示词**：打开案例详情，阅读并复制完整内容。列表摘要只用于预览，不是完整提示词。
4. **替换成自己的内容**：调整主体、品牌、文字、配色和画面比例，替换 `[TEXT]`、`[PRODUCT]` 等占位符。保留喜欢的构图、光线和材质描述。
5. **准备参考图**：如果提示词要求上传照片，请提供自己拥有或获准使用的图片，并写清哪些特征必须保留。案例效果图不一定是原始输入参考图。
6. **逐步迭代**：把改好的提示词用于你选择的图片工具。每轮优先调整一项，例如文字可读性、主体大小或背景复杂度，比较结果再继续。

例如，可以提出：“参考旅行纪念珐琅徽章的构图，把地点换成西湖，人物保持小比例，保留照片里的服装颜色，不要添加文字。”

提示词是创作起点，生成结果会受工具、设置和参考图影响，不能保证与示例完全相同。请在所用工具中确认费用和使用条件。

```bash
npx skills add cf12436/gptimage_prompts --skill aisaasgo-image-prompts
```

安装后，在支持技能的 AI 助手中明确提出：

> 使用 aisaasgo-image-prompts，帮我从案例库挑选适合咖啡新品发布的海报案例，保留暖色摄影风格，改成中文文案，输出可以直接复制的完整提示词，并列出参考案例来源。

这个技能自带完整案例和风格资料，负责查找、选择与改写提示词，也会提醒你补充必要的参考图。它不会自动调用付费图片接口，不要求填写 API 密钥，也不代表安装后即可免费生成图片。
