# AISaasGo 改写说明

## 从数据到提示词

1. 用标题、分类和标签查找案例，再读取完整 `prompt`。中文关键词无结果时可尝试对应英文分类或标签，不要虚构匹配结果。
2. 模板 `exampleCases` 对应案例 `id`；模板提供方向和注意事项，并非替代案例完整内容。
3. 建议按主体与任务、构图与层级、风格与材质、精确文字、比例、避免事项组织改写。只加入对本次需求有帮助的约束。
4. 文案用引号锁定；不应出现的元素写清楚；每轮优先改一个主要问题。

## 参考图

`image` 以 `/images/` 开头，表示站点上的案例展示资源。浏览入口为 https://image.aisaasgo.org ，不能因为字段存在就声称已查看图片。只有实际打开图片后才能描述其视觉细节。

单独安装技能时不附带图片二进制文件。用户应提供有权使用的输入照片；若无输入照片而原提示词依赖参考图，先确认补图或改成纯文字描述。避免将案例展示图误认为原始输入图。

## 建议输出

先给可复制的改写提示词，然后给简短依据：真实案例编号与标题、模板名称（如使用）、原作者 `sourceLabel`、原始 `sourceUrl` 和 `githubUrl`，最后列出尚缺的输入和下一轮可调项。

不得把改写标记为上游原文。若引用原文，应保持引用内容原样并明确来源。
